how i work

one loop, run on repeat.

  1. 01research

    Frame the real problem.

    Secondary research first, then primary: qualitative to learn why, quantitative to learn how many.

    secondary · primary · qual + quant
  2. 02design

    Prototype in hours.

    Testable interfaces, with every state and edge case.

    Figma · code
  3. 03testing

    Real people, real tools.

    Usability sessions, assistive tech included. Accessibility audited here.

    usability · WCAG 2.2
  4. 04iteration

    Follow the evidence.

    Rework what testing exposed, then test again.

    analytics · feedback
  5. 05ship

    Build the real thing.

    Production code, measured after launch.

    React · TypeScript
