# Portfolio design update — case studies

This is a **preview package**, not a change to your live Vercel website.

## What's updated
- Tesla, Accessibility, and A Century of Change: split-screen storytelling on desktop, with a sticky visual stage (like IDLA and SupplierMatch).
- All five updated pages now include a brief Situation / Task / Action / Result overview and matching story markers.
- RISE and Idaho CTE keep their visual demos and receive the same story overview.
- On phones and tablets, case-study images appear inline with the reading content, avoiding a tiny sticky sidebar.
- Images embedded in the three academic HTML files were saved as separate local image files for easier reuse. Their click-to-enlarge behavior was retained.

## How to preview (without coding)
1. Unzip the folder on your computer.
2. Open `index.html` in a browser.
3. Click **Work**, then open any case study.
4. Compare Tesla, Accessibility, Exhibit, RISE, and Idaho CTE with IDLA and SupplierMatch.
5. Also check on your phone before publishing; local previews are easiest using a desktop browser's device preview.

## Important for Vercel
Do **not** drag this ZIP directly onto Vercel Drop and expect it to update your existing project. Vercel Drop can create a separate project. Preview and approve the design before setting up updates to your existing portfolio project.
