# Grace Gwe — UX / Product Design Portfolio

Source for [gracegwedesign.com](https://www.gracegwedesign.com/), featuring enterprise product design, accessibility, educational experiences, and research-led case studies.

## Deployment

Static HTML/CSS/JS pages with Vercel hosting. GitHub will be the source of truth for changes after the migration from Vercel Drop.

## Chat assistant

The on-site pug assistant is called **ugu**. Its deterministic answers are built into the home page; optional AI responses require a server-side Vercel endpoint and a securely configured API key. No API keys belong in this repository.

## Case-study approach

Narrative-led introductions, visual evidence, decision rationale, implementation status, and honest outcomes. Avoid publishing confidential client details and unverified performance claims.
